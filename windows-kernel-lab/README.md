# Windows Kernel Lab Materials

This folder is reserved for the upcoming **ChronoRoot: Time-Traveling Through Kernel Trust Boundaries** materials.

Planned additions include:

- Windows driver reverse-engineering examples
- IOCTL analysis notes and diagrams
- Safe vulnerable-driver case studies
- Ghidra or other static-analysis walkthroughs
- User-mode to kernel-mode communication examples
- BYOVD background and defensive guidance
- Virtual machine setup and lab safety instructions
- Presentation demos and supporting files

> Materials will be added as the presentation develops.

## Safety Notice

All future content in this folder is intended for education, authorized research, and defensive security work. Kernel experiments should be performed only in an isolated virtual machine with snapshots and no sensitive data.
